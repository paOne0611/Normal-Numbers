This report brings together complementary perspectives on the theory of normal numbers. Beginning from definitions, base- $r$ expansions, Pillai's characterization, Wall's uniform distribution criterion, and concrete examples of both normal and non-normal numbers, we establish Borel's Normal Number Theorem through three distinct approaches: first, an elementary Rademacher and step-function proof that avoids Lebesgue integration altogether and second, Felix Hausdorff's constructive fourth-moment binomial argument in arbitrary integer bases $r \ge 2$.
